features:
  - title: 自造词
    details: 默认 ⌃⌥N 弹出造词窗口。选中的文字或两分钟内刚上屏的词会自动填入，编码按五笔规则生成，并列出同编码词来自哪个词库。
    link: /guide/custom-words
  - title: 日期与时间
    details: 输入 date、time、week，候选里就是当前日期、时间和星期。格式从「2026-09-28」到时间戳都有，用数字键选取。
    link: /guide/date-time
  - title: 快捷键
    details: 空格上屏、数字选词、单按 Shift 切换中英。翻页键和「; '」选二三候选可以在设置里改。
    link: /guide/shortcuts
  - title: 删掉不想要的候选
    details: 候选出现时，用造词那组修饰键加数字（默认 ⌃⌥1）打开确认框，看清词库和权重后再删除。
    link: /guide/custom-words#删除候选
  - title: 外观
    details: 横排或竖排、明暗两套颜色、首位高亮。也可以只显示圆点，或完全藏起候选条盲打。皮肤可以导出分享。
    link: /guide/appearance
  - title: 词库与同步
    details: 用户词按分组管理。登录后与码表助手、iOS 共用账号，对比、合并或覆盖同步，也可以拉取扩展词库。
    link: /guide/lexicon
