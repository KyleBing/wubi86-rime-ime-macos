# 日期与时间

输入四个字母 `date`、`time` 或 `week`，候选直接来自当前系统时间。不用先造词，也不依赖词库里的固定日期。

只认这四个字母。更短的别名会在打普通四码词时中途抢走候选，所以没有提供。

选词方式和普通候选一样：空格上第一个，数字键选对应项，翻页键看后面的格式。

下面用 2026-09-28 星期一 11:22:05 举例。你打出来的是当时的系统时间。

## date

日期在前，日期加时间排在后面，翻页可见。

<figure class="figure">
  <img src="/figures/date-bar.svg" alt="输入 date 后的候选条，第一项是 2026-09-28" />
  <figcaption>第一页是常用日期。继续翻页可以看到带时间的格式。</figcaption>
</figure>

| 顺序 | 示例 |
| --- | --- |
| 1 | `2026-09-28` |
| 2 | `2026/09/28` |
| 3 | `2026.09.28` |
| 4 | `20260928` |
| 5 | `2026年9月28日` |
| 6 | `9月28日` |
| 7 | `09-28` |
| 8 | `09/28` |
| 9 | `星期一` |
| 10 | `2026年9月28日 星期一` |
| 11 | `2026-09-28 11:22:05` |
| 12 | `2026/09/28 11:22:05` |
| 13 | `20260928112205` |
| 14 | `2026年9月28日 11时22分5秒` |
| 15 | `2026-09-28 11:22` |
| 16 | ISO 8601，按 UTC 输出，例如 `2026-09-28T03:22:05Z` |

月、日在数字格式里补零；「年月日」里的月和日不补零。

## time

第 3 个是秒级 Unix 时间戳，第 4 个是「时分」。毫秒时间戳在最后。

<figure class="figure">
  <img src="/figures/time-bar.svg" alt="输入 time 后的候选条，含 11:22:05 和时间戳" />
  <figcaption>时间戳随当前时刻变化，适合填日志或接口参数。</figcaption>
</figure>

| 顺序 | 示例 | 说明 |
| --- | --- | --- |
| 1 | `11:22:05` | 时:分:秒 |
| 2 | `11:22` | 时:分 |
| 3 | `1790565725` | 秒级时间戳 |
| 4 | `11时22分` | |
| 5 | `112205` | 紧凑到秒 |
| 6 | `1122` | 紧凑到分 |
| 7 | `11时22分5秒` | |
| 8 | `1790565725000` | 毫秒时间戳 |

小时用 24 小时制。个位数的「时分秒」中文格式不补零，冒号格式补零。

## week

周数按 ISO 8601，星期一是一周的开始。2026-09-28 是第 40 周。

<figure class="figure">
  <img src="/figures/week-bar.svg" alt="输入 week 后的候选条，含星期一和第 40 周" />
  <figcaption>中文星期、周数和英文星期名在同一组候选里。</figcaption>
</figure>

| 顺序 | 示例 |
| --- | --- |
| 1 | `星期一` |
| 2 | `周一` |
| 3 | `第40周` |
| 4 | `2026年第40周` |
| 5 | `礼拜一` |
| 6 | `Monday` |
| 7 | `Mon` |
| 8 | `2026-W40` |

## 和普通四码的关系

`date`、`time`、`week` 本身也是四码。候选很多，不会触发「四码唯一自动上屏」，需要你选一项。

如果这三个编码在词库里还有别的词，时间候选会插进来供选择，用数字键取你要的那一条。
