# 词库与同步

用户词、扩展词库和主码表是分开的。自造词进用户词，不改主码表文件。

## 用户词

「设置 → 用户词」左边是分组，右边是词条。

- 添加时填写词条和编码。有单字字典时，编码会按 [自造词](/guide/custom-words#编码怎么来) 同一套规则生成。
- 分组可以新建、重命名、删除。删分组不会把词条散到别处。
- 分组和词条都可以拖动排序。
- 快捷造词写入当前选中的分组。

## 和手机、码表助手同步

「设置 → 账户」登录 portal 账号，和码表助手、iOS 是同一个账号。默认地址是 `https://kylebing.cn/wubi/portal/`。

登录后回到「用户词」页：

| 操作 | 结果 |
| --- | --- |
| 对比差异 | 只拉取云端内容做比较，不改本地 |
| 增量合并 | 保留本地词条，并入云端多出来的 |
| 本地 → 云端 | 用本地覆盖云端 |
| 本地 ← 云端 | 用云端覆盖本地 |

箭头指向被覆盖的一侧。覆盖前建议先对比一次。

## 扩展词库

同一页的「获取扩展词库」会用线上扩展词库覆盖本地的扩展文件，不能在这个界面里逐条编辑。获取前请确认本地扩展词库没有需要留下的改动。

## 词库目录

「词库目录」管理 Rime 用户数据放在哪，以及重新部署、复位。

「单字字典」从当前选中的主码表抽出单字编码，供添加词条和快捷造词自动生成词组编码。换了主码表后，在这里重新生成一次字典。
