# 快捷键

默认按五笔习惯。翻页和「二三候选」写在 Rime 配置里，改完后下一次按键生效。造词快捷键改完立即生效。

## 选词

| 按键 | 作用 |
| --- | --- |
| 空格 | 上屏第一个候选 |
| `1` – `9` | 选择对应序号。候选条收成圆点或完全隐藏时同样有效 |
| `;` `'` | 第二、第三候选。可在「输入习惯」页关掉，只留数字键 |
| 回车 | 默认不上屏候选，直接交出已经打出的编码字母；开启**回车清码**后改为清空编码 |
| Esc | 清空当前编码 |

每页候选数在「外观配置」里调，范围 3–9，默认 9。

## 翻页

默认 **`-` `=` 和 `,` `.` 都能翻页**。在「设置 → 输入习惯 → 翻页键」里可以改成只用其中一套，或改成 `[` `]`。

Tab 也可以切到下一项候选，⇧Tab 切回上一项。

## 中英文

**单独按一下 Shift**（按下再松开，中间没有别的键）在中文和英文之间切换。英文模式下按键直接上屏。

切换时，光标旁会短暂显示当前状态：中文、英文，或大写锁定开启时的「大写」。大写优先于中英，样式相同。

按住 Shift 打大写字母，不会当成切换。造词窗口、删除确认框或候选排序窗口开着时，Shift 留给窗口，不切换模式。

也可以用 ⌃⇧2 切换中英。

## 造词和删词

| 按键 | 作用 |
| --- | --- |
| ⌃⌥N | 打开「添加自造词」。组合键可在「输入习惯」页修改 |
| ⌃⌥1 – ⌃⌥9 | 候选出现时，删除对应序号的词。修饰键跟着造词快捷键走 |
| ⌃⌥0 | 候选出现时，打开排序窗口，拖动调整顺序。只改被拖动那一条的权重，幅度可选 5 或 10。组合键可在「输入习惯」页的**排序**里单独修改 |

细节见 [自造词](/guide/custom-words)。

## 方案和字符

| 按键 | 作用 |
| --- | --- |
| ⌃⇧1 | 五笔 / 拼音方案切换 |
| ⌃⇧2 | 中文 / 英文 |
| ⌃⇧3 | 全角 / 半角 |
| ⌃⇧5 | 常用字集 / 扩展字集 |

## 编码里移动光标

还没上屏时，可以用 Emacs 风格的键编辑编码：

| 按键 | 作用 |
| --- | --- |
| ⌃B / ⌃F | 左移 / 右移 |
| ⌃A / ⌃E | 移到行首 / 行尾 |
| ⌃H | 删掉光标前一个字母 |
| ⌃G | 取消输入 |

## 四码唯一与回车清码

输入满四码且只剩一个候选时自动上屏。这是方案里的 `auto_select`。`date` 这类有多项候选的编码不会自动上屏。

「输入习惯」页的**空码清空**默认关闭。打开后，打满四码仍没有候选时自动清空输入的编码。

**回车清码**同样默认关闭。打开后，编码中按回车只清空编码，不把编码字母交给应用。

## 拼音反查

不会拆的字，用 **`z` + 拼音** 反查。拼音输完可以按 `'` 结束反查，再从候选里选字上屏。

例如不知道「玫」的五笔时，打 `zmei`，在候选里选「玫」。
