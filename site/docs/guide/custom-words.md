# 自造词

常用的人名、项目名、口头语，打一遍即可收进用户词。之后按生成的编码就能打出来，并排在前面。

## 打开窗口

默认快捷键是 **⌃⌥N**（Control + Option + N）。

在「设置 → 按键 → 造词」里点一下按钮，再按下新的组合键即可更换。至少要带一个修饰键。改完立刻生效，不用重新部署。

打开时，词条按这个顺序填入：

1. 快捷键按下时，当前软件里选中的文字。
2. 选区读不到时，两分钟内刚上屏、且含汉字的词。
3. 都没有，就留空，自己输入。

词条一有汉字，编码会按下面的规则自动填上，也可以改。

## 编码怎么来

编码来自「词库目录」里的单字字典。字典从当前主码表抽出每个字的编码。还没有字典时，造词会用主码表生成一次。

只取词条里的汉字，标点、英文和数字不参与。某个字在字典里没有，编码留空，需要自己补。

| 字数 | 规则 | 例子 |
| --- | --- | --- |
| 1 | 用这个字已有的编码 | 中 → `khk` |
| 2 | 各取前两码 | 中国 → `khlg` |
| 3 | 前两字各取首码，第三字取前两码 | 计算机 → `ytsm` |
| 4 字及以上 | 前三字各取首码，再取最后一字的首码 | 中华人民共和国 → `kwwl` |

例子里的单字码以 86 极点码表为准。你改过码表或单字字典后，生成结果跟着字典走。

## 权重和分组

权重可以空着。空着或小于 `100000` 时，造词会写成 `100000`，让新词排到同编码候选的前面。已经不低于这个数的，保持你填的值。

分组用窗口里的下拉菜单，默认是「用户词」页当前选中的那一组。没有分组时会建一个未命名组。

窗口下方列出同编码的已有词，并标明来自哪个词库，避免和主词库、扩展词库撞码还不知道。

## 窗口里的按键

| 按键 | 作用 |
| --- | --- |
| 回车 | 添加。词条框还在组字时，第一次回车先上屏，再按一次才写入 |
| Esc | 关闭窗口 |
| Tab / ⇧Tab | 在词条、编码、权重之间切换 |
| ⌘A / C / V / X / Z | 全选、复制、粘贴、剪切、撤销 |

添加后词库会重新加载，马上可以打出来。

## 在设置里管理

「设置 → 用户词」是同一批词：左边分组，右边词条。可以添加、改编码、拖动排序、重命名或删除分组。

造词快捷键写入的就是这里选中的分组。

## 删除候选

<figure class="figure">
  <img src="/figures/delete-candidate.svg" alt="删除候选确认框，显示词库、权重和同编码词" />
  <figcaption>确认后从所选词库删掉这一条，并把刚才的编码重新输回去。</figcaption>
</figure>

候选条出现时，按 **造词那组修饰键 + 数字**。默认造词是 ⌃⌥N，删除就是 **⌃⌥1** 到 **⌃⌥9**，数字对应候选序号。

确认框会显示：

- 词和编码
- 来自哪个词库（用户词、扩展词库或主词库），有多处时可以选
- 权重和备注
- 同编码的其他词

回车确认，Esc 取消。标点或临时候选不在词库里，确认按钮不可用。

「仅圆点」或「不显示」候选条时，数字序号仍然对应，快捷键一样能删。
