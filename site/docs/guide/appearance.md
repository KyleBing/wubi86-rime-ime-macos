# 外观

候选条是一块不抢焦点的面板，编码以下划线留在光标处。颜色分开存浅色和深色，跟着系统外观走。

在「设置 → 外观配置」里调整。本地修改自动保存。

## 候选怎么显示

三种方式选一种：

| 方式 | 效果 |
| --- | --- |
| 候选框 | 展开词条，默认样式 |
| 仅圆点 | 不展开词，只用小圆点表示这一页有几个候选，适合盲打 |
| 不显示 | 连圆点也没有，只留编码下划线 |

后两种仍然用数字键、空格和翻页键选词。

## 布局

- 水平或垂直排列
- 每页 3–9 个候选。这里改完会写进 Rime 配置并立即重新部署，不需要手动点部署
- 序号可以是「1.」、纯数字，或关掉
- 字体：系统默认、苹方、黑体、宋体、楷体、华文宋体、冬青黑体
- 候选和序号的字号、粗细、间距
- 内边距、圆角、阴影
- 「距光标上」「距光标左」控制候选窗离插入点多远
- 首位候选（空格上屏的那一项）可以单独高亮
- 备注：默认显示词条的备注，可取消勾选隐藏。优先用 Rime 候选的 `comment`，没有时显示码表第四列的备注（云端扩展词库的备注写在这里）；字号、粗细和明暗配色可单独设置

## 皮肤

当前外观可以导出成 JSON，在另一台设备上从文件导入。内置一套默认皮肤，另外有 8 个位置用来留下自己的主题。

导出文件里包含名称、作者、尺寸和明暗两套颜色。版本不兼容时导入会拒绝，避免把旧格式写坏。
