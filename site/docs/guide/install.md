# 安装

玫枫五笔是系统输入法，需要先装进「输入法」列表，再在系统设置里启用。

## 启用

1. 打开「玫枫五笔」。
2. 点「安装 / 更新输入法」。
3. 打开「系统设置 → 键盘 → 输入法」。已经启用的话，用菜单栏输入法图标即可切换。
4. 列表里还没有：点「+」→ 简体中文 → 玫枫五笔。
5. 若安装后列表仍不出现，注销一次再看。

设置从菜单栏输入法图标里的「玫枫五笔设置…」进入，也可以在主窗口点「打开输入法设置」。

## 列表里出现重复项

主窗口有「修复 / 清理重复项」。它会清掉构建目录里误注册的副本。平时不用点。

## 第一次输入

切换到玫枫五笔后，单独按一下 Shift 确认是中文模式，然后正常打五笔。数字 `1`–`9` 选词，空格上屏第一个候选。

打不出想要的词时，用 [自造词](/guide/custom-words) 加进去。要填今天的日期，直接打 `date`。
