## macOS 提示「无法打开」时

安装包没有配置 Apple 开发者证书时（自签名包），首次打开会被 Gatekeeper 拦截，提示「无法打开」或「已损坏」。按下面顺序试，一般第 1 步就能打开：

1. **右键打开**：把 DMG 里的「玫枫五笔.app」拖进「应用程序」，在访达里**右键**点它 →「打开」，弹窗里再点一次「打开」。
2. **系统设置放行**：「系统设置 → 隐私与安全性」，拉到底部点「仍要打开」。
3. **终端去除隔离属性**（前两步无效，或提示「已损坏」时）：

   ```bash
   xattr -cr "/Applications/玫枫五笔.app"
   ```

   执行后再打开一次。如果 app 放在别处，把路径换成实际的 `.app` 路径。

打开宿主 App 后点「安装 / 更新输入法」，再到「系统设置 → 键盘 → 输入法」里启用玫枫五笔。
